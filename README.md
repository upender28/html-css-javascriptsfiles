## Project Overview

This project is a structured practical-laboratory website containing working demonstrations for HTML, CSS, JavaScript, browser APIs, web storage, mini projects, and Node.js backend concepts.

The interface has been organized as a professional academic practical record so that each experiment can be opened, studied, executed, and reviewed independently.

## Experiment Format

Browser-based experiments are organized to provide:

1. **Aim** — the purpose of the experiment.
2. **Description** — the concept being demonstrated.
3. **Steps / Procedure** — the practical procedure.
4. **Working Implementation / Output** — an interactive demonstration where applicable.
5. **Expected Output** — the result to verify.
6. **Navigation** — convenient links between the home page, module index, and experiment pages.

## How to Run

### Browser Experiments

1. Extract the ZIP archive.
2. Open the `practical-website` folder.
3. Open `index.html` in a modern web browser.
4. Select the required practical module.
5. Open an experiment and follow its procedure.
6. Test the working demonstration and compare it with the expected output.

### Node.js Experiments

1. Install Node.js.
2. Open a terminal in the relevant experiment directory.
3. Run simple programs with:
   ```bash
   node filename.js
   ```
4. Install project-specific packages when required, for example:
   ```bash
   npm install express
   ```
5. Start the server and open the displayed localhost address.
6. Use a browser or an API client such as Postman for REST/API experiments where appropriate.

## Technical Notes

- Some browser APIs require user permission, such as geolocation.
- API-based demonstrations may require an internet connection.
- Node.js backend experiments are intended to be executed from a terminal/server environment rather than by double-clicking an HTML file.
- Database, authentication, and advanced backend experiments may require additional packages, services, or configuration.
- The project uses a responsive shared stylesheet so the practical pages remain consistent across desktop, tablet, and mobile screen sizes.
